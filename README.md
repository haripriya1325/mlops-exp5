# MLOps Experiment 5 - Iris FastAPI

## Run

1. Create and activate a virtual environment.
2. Install dependencies:
   pip install -r requirements.txt
3. Train the model:
   python train_model.py
4. Start the API:
   uvicorn app.main:app --reload

Swagger UI:
http://127.0.0.1:8000/docs

API status:
http://127.0.0.1:8000/
